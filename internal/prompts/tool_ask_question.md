Put a choice to the user and wait for the answer. Returns what they chose, or what
they typed instead.

question is what is being asked, in one sentence. options is two to four answers,
each a label and an optional description of what that answer means. Set
multi_select when more than one option can be chosen together.

Reach for it when a choice changes the work and the answer is not in the project.
Do not ask what you can read, and do not ask for permission to run a tool.
