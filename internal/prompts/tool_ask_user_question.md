Ask the user one or more questions and wait for the answers; returns each choice, or what they typed instead.

questions: one, or several that do not depend on one another so they are answered together. Each is a question, one sentence, with options, two to four, each a label plus an optional description. Set multi_select on a question when several of its options may be chosen together.

Use when a choice changes the work and the answer is not in the project.
Do not ask what you can read, or for permission to run a tool.
