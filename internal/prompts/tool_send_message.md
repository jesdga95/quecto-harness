Send one message to the agent at the other end of a run_agent. It joins the turn
that agent is in the middle of, or starts one when it is idle.

to is the handle run_agent answered with, or parent when another agent gave you
this task. text is the message.

Reach for it to answer a question, to add something you left out, or to say a
task is no longer wanted. It does not wait for a reply; a reply arrives as a
message of its own.
