Hand a task to another agent. It starts at once and works in this project while
you carry on, so this call answers with its handle rather than its result.

agent is the name of the agent to run it. task is the whole brief: that agent
sees none of this conversation, so say what to do, where to look and what to
answer with.

It sends you a message when it is done, and send_message reaches it before then.
Reach for it when the work is separable, or when another agent suits it better
than you do.
